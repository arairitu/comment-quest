# 🎮 コメントクエスト 〜コメントとギフトで勇者を育てろ！〜
## 自律型 TikTok LIVE 参加型RPG 完成版企画書

---

## 1. コンセプト

**視聴者全員で1人の勇者を育てる、コメント＆ギフト参加型ライブRPG。**

顔出しなしで自律稼働。視聴者のコメントとギフトがリアルタイムで「ゲーム内行動」に直結し、全員で一丸となってダンジョンを突き進む。

- **ビジュアル:** 2Dドット絵風、レトロRPGの世界観
- **ゲーム性:** ダンジョンを潜り続ける放置／インクリメンタル系
- **共有システム:** 全員で「1人の勇者」を共有。ボス戦は全員で共闘
- **タイトル案:** コメントクエスト（サブ: コメントとギフトで勇者を育てろ！）

---

## 2. 設計の核心 — 3層の参加バランス

この企画の成否を分ける最重要ポイント。**高額ギフトだけが勝つゲームにしない。**

| 層 | 参加手段 | 役割 |
|---|---|---|
| 無課金層 | コメント | 攻撃・回復・作戦で「軍師」として参加 |
| 少額ギフト層 | 小〜中ギフト | 連撃コンボ・ガチャ・宝箱 |
| 高額ギフト層 | 大〜超大ギフト | 必殺技・ピンチ救済・覚醒演出で主役級の見せ場 |

> **3つの両立:** 無課金でも参加できる／少額でも役に立つ／高額はめちゃくちゃ目立つ

---

## 3. 参加方法（コメント5種からスタート）

初見が3秒で理解できるよう、画面に常時表示する。**最初は5種類だけ**で十分。慣れてきたら追加。

```
=== 初見さんへ！コメントで勇者を助けよう ===
「攻撃」→ 勇者が攻撃（戦士）
「回復」→ HP回復（僧侶）
「魔法」→ 属性ダメージ（魔法使い）
「守る」→ 防御アップ（タンク）
「盗む」→ ゴールド獲得（シーフ）
```

| コメント | 役割 | 効果 |
|---|---|---|
| 攻撃 | 戦士 | 通常攻撃 |
| 回復 | 僧侶 | HPを少し回復 |
| 魔法 | 魔法使い | 敵に属性ダメージ |
| 守る | タンク | 被ダメージ軽減 |
| 盗む | シーフ | ゴールド獲得 |

これにより「回復足りない！みんな『回復』打って！」のような**コメント勢主導の盛り上がり**が生まれる。

## 4. ギフト設計（4ティア）

### 小ギフト（1〜9コイン｜バラ・いいね系）
**「1個だと弱い」ではなく「みんなで積み上げると強い」設計。**

- 1個 = 勇者の連撃1回
- 10個 = コンボ発生
- 50個 = ラッシュモード
- 100個 = 全体バフ
- **イベント例:** 「バラ100本チャレンジ！達成で30秒間、攻撃速度2倍！」
- 「ゴールドラッシュ」: 10秒間、獲得ゴールド倍増

### 中ギフト（10〜99コイン｜コントローラー系）
画面中央に**宝箱が出現してパカッと開く演出**を入れる。

- ガチャ1回発動
- スキル獲得 / 武器強化 / 回復ポーション
- 演出例: 「○○さんのギフトで宝箱出現！中身：雷の剣 R」

### 大ギフト（100〜999コイン｜ライオン系）
**配信の山場。** 画面全体が光る派手な演出。

- 必殺技発動（例:「ドラゴンスラッシュ！！」）
- 中ボス・強敵の強制召喚
- レア装備確定 / ステータス大強化

### 超大ギフト（1000コイン〜｜ユニバース・城系）
**「勝ち確」ではなく「大逆転のチャンス」にする。** 強すぎるとゲームが壊れる。

- 女神の奇跡（全滅寸前から全員復活＋ボス大ダメージ）
- 勇者覚醒: **30秒間、攻撃力5倍・被ダメージ半減**（※10倍無敵より5倍＋半減が適正バランス）

## 5. 育成・ガチャシステム

### 勇者ステータス
- **レベル:** 累積ギフト数・敵討伐数で自動上昇
- **基本能力:** HP / ATK / DEF / SPD / MAG
- **装備スロット:** 武器・防具・アクセサリー（ガチャ入手）
- **スキル枠:** ガチャ入手の魔法・パッシブをセット

### ガチャ
- **種類:** 武器ガチャ（剣・斧・魔法書）、スキルガチャ（ファイアボール・ヒール等）
- **レアリティ＆排出率:**

| レアリティ | 排出率 |
|---|---|
| N（通常） | 60% |
| R（レア） | 30% |
| SR（超レア） | 8% |
| SSR（最高） | 2% |

- SSR当選時は画面全体にド派手なエフェクトで盛り上げる

## 6. ダンジョン構造（5ゾーン × 無限ループ）

ゾーンクリアでフィールドが切り替わり、視覚的な変化で飽きを防ぐ。

| ゾーン | フロア | 敵 | ボス | 難度 |
|---|---|---|---|---|
| Zone 1 草原・森 | B1〜5F | スライム・ゴブリン・狼 | 森の番人 | 入門 |
| Zone 2 洞窟・遺跡 | B6〜10F | コウモリ・スケルトン・トロル | 古代の守護者 | 中級 |
| Zone 3 溶岩地帯 | B11〜15F | 炎ゴーレム・サラマンダー | 炎竜 | 上級 |
| Zone 4 氷の神殿 | B16〜20F | 氷の精霊・フロストジャイアント | 氷の女王 | 超上級 |
| Zone 5 魔王城 | B21F〜 | デーモン・暗黒騎士 | 魔王（周回で強化） | FINAL |

### フロアの種類
- **通常フロア:** 雑魚3〜5体と自動戦闘
- **イベントフロア:** ショップ・宝箱・謎解きがランダム発生
- **ボスフロア:** コメント参加で視聴者全員が共闘

## 7. ボス戦システム

ただ殴るだけだと飽きるので、**HPごとにイベント**を入れて配信者がリアクションしやすい「事件」を作る。

| HP | イベント |
|---|---|
| 75% | ボスが怒り状態に！攻撃力アップ |
| 50% | **作戦会議タイム！** 30秒以内にコメントで作戦決定（攻撃＝総攻撃／回復＝立て直し／守る＝防御重視） |
| 25% | 最終形態！回復効果半減。ギフト・コメントで押し切れ |

### 🏆 ラストヒットシステム（最重要）
撃破時、**最後に攻撃したコメント／ギフトの人の名前を大きく表示。**

```
LAST HIT！
○○さんの攻撃で魔王撃破！
```

→ 嬉しい・スクショされやすい・また参加したくなる。**「名前が出る快感」の中核。**

3位：□□さん　回復MVP

→ 全員が主役になれる。画面端に常時表示して競争心を刺激。

## 9. 無料ガチャゲージ（無課金巻き込みの目玉）

- コメントが増えるほど「応援ゲージ」上昇
- 100%で**その場の全員が引ける無料10連ガチャ**発動
- 有料ガチャ直引きより、全体ゲージ→全員ガチャの方が安全で盛り上がる

```
応援ゲージ100%達成！
全員参加の無料10連ガチャタイム！
```

## 11. 月次シーズン制（転生）

インフレ・マンネリ防止のため**1ヶ月ごとにリセット**。ただし強さではなく**名誉を引き継ぐ**。

- シーズン1：勇者編 → S2：魔法使い編 → S3：シーフ編 → S4：魔王討伐編
- **引き継ぎ要素（名誉系）:** 限定バッジ・称号・待機画面に名前掲載・前シーズンMVP表示・勇者像に名前刻印
- ゲーム内の強さは引き継ぎすぎない（新規が入りにくくなるため）

## 15.5. グローバル対応（配信対象は世界）

2Dドット絵RPGは「視覚言語」で伝わるためグローバル向き。HPバー・ダメージ数字・スライム・ドラゴン・剣は言語を超えて通じる。海外のidle/gacha/レトロRPG系は人気が高い。

### コマンドは言語非依存に（最重要）
コメントコマンドを **絵文字 ＋ 数字 ＋ 多言語キーワードの3併用**で受け付ける。

| アクション | 絵文字 | 数字 | 多言語キーワード例 |
|---|---|---|---|
| 攻撃 | ⚔️ | 1 | 攻撃 / attack / atk / atacar / 공격 / 攻击 |
| 回復 | 💚 | 2 | 回復 / heal / hp / curar / 힐 / 治疗 |
| 守る | 🛡️ | 3 | 守る / defend / guard / def / 방어 / 防御 |
| 魔法 | 🔥 | 4 | 魔法 / magic / mag / magia / 마법 / 魔法 |
| 盗む | 💰 | 5 | 盗む / steal / gold / robar / 훔치기 / 偷 |

### その他の原則
- **UIはアイコン/数字ファースト** ── テキストを減らせば自動で多言語対応。操作説明も絵文字＋数字で表示すれば翻訳不要。
- **世界観は今のままでOK** ── ファンタジー（騎士・ドラゴン・魔王・スライム）は世界共通語彙。日本ローカルな小ネタのみ避ける。
- **タイトル:** "Comment Quest"。サブタイトルのみ多言語化（"Grow the hero with comments & gifts!"）。
- **曜日イベントは時差を考慮** ── 固定時刻だと地域差が出る。セッション基準 or 時間ローテーションで公平に。世界中に視聴者がいれば24時間配信の可能性も。
- **要確認:** TikTok LIVEの収益化対象は国・地域で条件が異なり変更もある。実装前に最新情報を確認。

## 16. 成功の5大ポイント

1. **高額ギフトだけが勝つゲームにしない**（3層バランス）
